# Atlas Crew — Portfolio Decision Log

Architecture Decision Records (ADRs) for decisions that span **more than one
Atlas Crew repository** — platform-wide conventions, cross-service contracts,
shared infrastructure, and security posture that the whole portfolio inherits.

**Scope test:** if a decision only affects one repo, its ADR belongs in that
repo under `docs/architecture/decisions/`. It lands here only when it binds
two or more of: `synapse`, `Chimera`, `Crucible`, `Bridge`, `Apparatus`
(`Facet` is standalone and keeps its own decision log).

## Format

One file per decision: `adr-NNNN-short-slug.md`, numbered sequentially, never
reused. Copy [`adr-template.md`](./adr-template.md) to start. Keep the record
immutable once `Accepted` — supersede with a new ADR rather than editing, and
link the two.
